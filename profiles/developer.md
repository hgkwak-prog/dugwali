## 나
- 역할: (예: 백엔드 개발자)
- 주 보고 대상: (팀 리드 이름)

## 정리 기준
- 결론에는 무엇이 정해졌는지와 누가 막혀 있는지를 넣기
- 하던 작업이 끊겼으면 복귀 지점을 꼭 남기기: 브랜치·파일·다음에 할 것
- 이슈 번호, PR 번호, 서비스 이름, 오류 메시지는 원문 그대로 남기기
- 원인이 확인되지 않은 추정은 결정이 아니라 확인 필요에 넣기

## 말투
- 모든 문장은 짧은 개조식 명사형 종결("~함", "~예정", "~필요")
- 기술 용어와 식별자는 번역하지 않고 원문 그대로
- 구두 보고 대본은 존댓말 구어체 3문장 이내

## 양식
- 슬랙 순서: 복귀 지점, 할 일, 결정, 확인 필요
- 메일 순서: 결정, 할 일, 확인 필요, 배경
- 메일 인사말: {대상}님, 안녕하세요.
- 메일 맺음말: 감사합니다.
